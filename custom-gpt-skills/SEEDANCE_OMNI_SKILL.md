# SKILL: SEEDANCE 2.5 → OMNI FLASH PIPELINE (с заменой дублёра на реального человека)

## Когда активировать
Триггер: пользователь пишет что-то вроде «делаем ролик в Omni Flash и Seedance 2.5». С этого момента действуй по протоколу ниже до явной отмены пользователем.

## Жёсткие вводные (не предлагать альтернативы)
- **Avatar-режим Omni недоступен** (регион). Никогда не предлагать его как решение.
- **Omni Edit Video** (загрузка готового видео + «замени лицо») даёт слабое сходство — использовать ТОЛЬКО для кадров, где лицо маленькое/в профиль/спиной к камере/далеко от камеры.
- **Omni Create Video** (генерация из фото) даёт хорошее сходство — это основной инструмент для финального видео с реальным человеком в кадре крупным/средним планом.
- **Seedance 2.5** — источник операторской работы и физики движения (motion reference), финальным носителем лица пользователя НЕ является.
- **Nano Banana** — безлимитный движок для картинок: превращает кадр с дублёром в кадр с реальным человеком, сохраняя сцену/свет/камеру.
- Seedance-видео нельзя импортировать в Omni Create Video — туда идут только картинки. Значит между нейросетями передаётся не файл, а СОСТОЯНИЕ КАДРА (bridge frame).

## Пошаговый протокол

### Шаг 0 — Приём материалов
Запросить у пользователя (если не приложено):
1. Готовое видео из Seedance с дублёром(-ами).
2. Фото пользователя (несколько ракурсов, если есть).
3. Если в видео второй дублёр (например, девушка) — фото реального человека, которым его заменяют.
Сформировать таблицу замены:

| Роль в видео | Кто на видео (дублёр) | Кем заменить | Фото-референс |
|---|---|---|---|
| Персонаж 1 | дублёр-мужчина | Пользователь | [фото] |
| Персонаж 2 | дублёр-девушка | [имя/референс] | [фото] |

### Шаг 1 — Анализ видео
Просмотреть загрученное видео и выдать **ПОЛНОЕ ОПИСАНИЕ**, используя все ранее закреплённые правила и инструкции (формат промта, консистентность персонажей, тайм-коды, язык). Описание включает:
- Локацию, свет, время суток
- Движение камеры покадрово
- Действия персонажа(ей) с тайм-кодами
- Ключевые объекты (машина, реквизит и т.д.)

### Шаг 2 — Мастер-промт
На основе анализа собрать и вывести **ПОЛНЫЙ ПРОМТ ЭТОГО РОЛИКА** (как если бы это был исходный промт для Seedance) — фиксирует "правду" о ролике, дальше всё строится от него.

### Шаг 3 — Сторибord с заменой персонажей
Разбить ролик на ключевые кадры (старт / ключевая поза / кульминация движения / финальное положение — либо каждые 2-3 сек). На каждый кадр:

```
КАДР [номер] — [тайм-код, напр. 0:00–0:03]
Камера: [движение/план]
Действие: [что происходит]
Персонажи в кадре: [из таблицы замены — уже С РЕАЛЬНЫМИ ЛЮДЬМИ вместо дублёров]
Nano Banana instruction: сохранить сцену/свет/камеру/объекты; заменить [дублёр] → [референс-фото], идентичность и одежда персонажа неизменны между кадрами
```

Если дублёров несколько — в каждом кадре явно указывать, кто из реальных людей на месте какого дублёра, не путать местами между кадрами.

### Шаг 4 — Финальный промт для Omni Create Video
Для каждого bridge-кадра — детальный промт на английском (язык генератора, per правило языка): что происходит дальше, куда движется камера, что делает персонаж — продолжение операторской задумки Seedance, а не новая сцена.

### Шаг 5 — Сегментация для роликов 20–30 сек
Если пользователь просит ролик длиннее 10 сек:
1. Делить весь сторибord и промты на части по 10 сек: ЧАСТЬ 1 (0–10), ЧАСТЬ 2 (10–20), ЧАСТЬ 3 (20–30).
2. Для каждой части фиксировать:
   - **START FRAME** — с чего часть начинается (для части 2+ это END FRAME предыдущей части)
   - **END FRAME** — чем часть заканчивается, что становится стартом следующей
3. На стыке частей обязательно закладывать **скрытую склейку** из библиотеки: дверь закрывает объектив, человек/объект проходит перед камерой, whip-pan, вспышка, сильный blur, дым, проезд камеры вплотную к объекту, тёмное стекло. Это скрывает микро-разницу между генерациями.
4. В выводе явно писать: «ЧАСТЬ 2 — продолжение с кадра [END FRAME части 1], действие продолжается: …» — никогда не начинать часть с нуля, если это не первая часть.

## Формат финальной выдачи (по порядку)
1. Полное описание видео (Шаг 1)
2. Мастер-промт (Шаг 2)
3. Таблица замены персонажей
4. Сторибord с покадровыми Nano Banana-инструкциями (Шаг 3)
5. Промты для Omni Create Video, при длине >10 сек — разбитые на пронумерованные части с START/END FRAME и указанием скрытой склейки (Шаг 4–5)

## Чек-лист перед выдачей
- [ ] Нигде не упомянут Avatar-режим
- [ ] Крупные/средние планы идут через Create Video, не через Edit Video
- [ ] Идентичность каждого реального человека не путается между кадрами/частями
- [ ] Каждая часть >1 явно продолжает предыдущую, а не начинается заново
- [ ] На каждом стыке частей есть элемент скрытой склейки
- [ ] Промты для генератора — на английском, комментарии для пользователя — на русском
